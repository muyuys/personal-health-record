# 021 明细数据折叠展示（默认折叠）

- 优先级：P2
- 问题：各页「记录明细」表格默认全部展开，大列表（体重 420 / 睡眠 1156 / 检验 45）一进页面就被长表格淹没。
- 目标：所有「记录明细」区块改为**可折叠面板，默认折叠**；展开后才显示表格与分页控件。
- 范围：
  - 统一用 `<details>`/`<summary>` 或按钮 + CSS 折叠容器；标题栏显示条数，点击展开/收起。
  - 覆盖：`js/app.views.body.js` 体重/睡眠/生命体征/成分「记录明细」；`js/app.views.health.js`「全部检验记录」表格；其他渲染明细表的地方（如就诊/用药若无表格可不动）。
  - 折叠状态默认 `closed`；展开状态仅存在内存（`ui` 里加 `openDetails:{...}`），刷新回到折叠，无需持久化。
  - 分页控件与统计条仅在展开后渲染/显示（可仍在 DOM 内，但外壳隐藏也可，注意分页点击不因折叠丢失状态）。
  - `assets/styles.css` 加折叠样式（沿用 `--line-2`/`--muted-3`/`--card` 令牌，`summary` 去掉默认三角，配 chevron 图标）。
- 验收：
  - 进入页面时明细表默认折叠，只看到标题 + 「展开」提示。
  - 点标题展开显示表格 + 统计条 + 分页；再点收起。
  - 展开后分页/翻页正常工作；切换到别的页再回来恢复默认折叠。
  - `node --check` 通过；页面 200。
- 关联：`docs/tasks/020`（同批但独立文件，避免并发改同一行冲突时以本卡为准）。
