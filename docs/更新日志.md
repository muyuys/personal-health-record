# 更新日志

记录本次健康档案功能扩展与界面调整。当前应用版本为 **v0.1.2**，日期按香港时间记录。

本日志依据本轮开发改动和 [应用版本记录](../assets/release.json) 整理，版本条目不等同于 Git 标签或对外发布。仅补充日志不增加应用版本号。

## 本次更新概览

本次更新将个人档案扩展为可管理家庭成员的本机健康平台，新增多模态 AI 问答、Magpie / 自定义 API 连接、MCP 操作接口和指标历史汇总，并将连接配置整理为分组设置。

## 未发布 · 界面细节优化

- 桌面侧边栏默认收起为图标栏，可手动展开完整菜单；悬停显示入口名称。
- 侧边栏展开与收起增加平滑过渡，统一导航图标尺寸，固定展开前后的图标中心与纵向位置。
- AI 模型选择改为可搜索的分组面板，标记默认模型与当前选择；支持键盘选择、Esc 关闭与窄屏定位。
- 桌面设置分类栏靠近全局侧边栏，右侧内容独立滚动，切换长短分组时分类栏保持稳定。
- 成员管理、AI 问答和健康主题靠左布局，与设置页保持一致的内容起点。
- 档案切换与新增集中到“我的”浮层，桌面侧栏和手机底栏共用入口；保留成员管理、个人资料与数据入口。
- 备份下载链接携带当前成员标识，避免直接下载时回到默认档案。
- AI 问答的当前档案移到输入框左下角，点开可就地切换或新增档案；切换后仍留在问答页，只读取该档案自己的记录与问答历史。
- 手机端指标摘要改为两列，最近结果优先，最低／最高值单列展示。
- 手机端逐次记录改为分行明细，保留日期、结果、参考范围、来源和备注，减少横向滚动。
- AI 问答收紧引导区留白，依据与范围在手机上默认收起，可展开查看。
- 设置长地址在手机上独立成行，补强表单焦点提示，扩大常用按钮的点击区域。
- 修复 320px 窄屏下设置分类导航导致的整页横向溢出。
- AI 问答改为对话式排版：提问是右对齐的浅绿气泡，回答不再套块，直接按正文排在底色上；跨天插入「今天／昨天」分隔，每条回答带用时与时间，底部可一键复制原文。
- 回答支持 Markdown 渲染（标题、列表、表格、引用、代码、链接），来源列表改为逐条记录卡，数值与参考区间合并展示。
- 提问后先显示等待态，回答返回后就地替换；失败时问题内容留在输入框，改动一句即可重试。
- 去掉问答页重复的通用免责脚注与「回答模型」说明行，转发提示并入「依据与范围」；空态改为可点击的示例问题。
- 问答输入区固定在页面底部（手机端抬到导航栏上方），阅读长回答时不用滚到底就能继续提问；上沿留渐变避免正文被硬切，滚到末尾自然回落，不遮挡最后一条。
- 问答页支持 `/reset` 指令（`/clear`、`/清空` 同义）：输入框里输入后按钮变为「执行」，回车清空当前档案已保存的问答记录；只删问答与来源，不动检验、报告等记录，也不影响其他成员。清空后留一条「已清空 N 条」的提示并回到空态。

## v0.1.2 · 2026-11-07

- 按“常规、模型连接、MCP、关于”组织设置，右侧只显示当前选中的分类。

- 旧的模型连接、MCP 和关于入口仍可定位到对应分类。

## v0.1.0 · 2026-11-07

从本版本开始建立应用版本记录，纳入此前本轮开发完成的能力。

### 家庭成员独立档案

- 支持新增成员、编辑称呼与关系，以及切换查看不同成员的档案。
- 原有数据库和静态健康摘要归属默认成员，保留原有资料。
- 新成员使用独立数据库、报告图片目录、问答历史和浏览器降级缓存，不继承默认成员的静态病史、用药、待办与目标。
- 当前成员保存在页面 URL 中，不改变其他标签页正在查看的成员。

### 多模态 AI 问答与报告解析

- 根据当前成员的检验、报告、就诊、用药、病史与日常健康记录检索作答。
- 回答附带检索来源，支持展开核对，并按成员保存问答历史与所用模型。
- 报告图片直接提供给支持图片输入的模型；主服务不再加载本地 RapidOCR / ONNX Runtime。
- 报告解析结果经核对后保存，解析文字随报告保留；保存原件后，也可在问答中直接读图。
- 问答最多附加三张相关报告图片，并在来源中标记已提供图片的报告。
- 模型不可用、未配置或输出无法解析时显示错误，不生成虚假的成功结果。

### Magpie 与自定义模型连接

- 默认接入本机 Magpie，支持转发文字和图片请求。
- 支持配置兼容 Chat Completions 格式的 API 地址、API Key 与默认模型，保存后立即生效。
- 模型列表从服务接口读取，筛选标注支持图片输入的模型，可刷新并为单次对话切换模型。
- 对话输入框内使用紧凑选择器：收起显示简称，展开显示完整模型 ID。
- 密钥由本机服务端保存，不回显到配置接口；留空可保留，亦可明确清除。
- 更换 API 地址时要求重新填写或清除已有密钥，避免误用原服务凭证。
- 页面说明资料发送范围，明确 Magpie 会继续转发至上游模型服务。

### MCP 与 agent 操作

- 增加本机 stdio MCP 桥接程序，支持初始化协商与工具发现。
- 提供成员列表与管理、读取档案、单条记录新增或更新、删除记录及 AI 问答六类工具。
- 记录操作要求显式指定成员 ID，校验必填字段、数值、日期和关联记录所属成员。
- 删除报告或就诊记录时，解除对应的检验、就诊或用药关联。
- 使用本机凭证连接服务，设置页生成匹配当前 Python、目录、端口和数据库的 MCP 配置，支持复制。

### 按指标汇总与查看变化

- 新增独立“指标趋势”入口，覆盖检验、体重与身体成分、围度、生命体征及睡眠指标。
- 支持搜索指标、按来源筛选，以及全部、近 90 天、近一年和自定义日期范围。
- 显示最近结果、与上一条的差值、范围内最低 / 最高值和逐次明细。
- 曲线保留每次原始测量，不自动取平均；缺失值不补零，定性结果只展示历史明细。
- 不同类别、单位、样本及血糖测量条件分别汇总，不自动换算或推断。
- 参考范围变化时不套用最后一次范围作为全部历史底色，明细保留各次实际范围。
- 报告关联项目和全部检验记录中的项目名称可直接跳转到对应指标历史。

### 设置与关于

- 将平台地址、模型连接与 MCP 配置集中到设置，成员页面专注成员管理。
- 增加关于与版本记录，展示版本号、日期及功能说明。
- 版本信息统一维护在 `assets/release.json`。

## 验证与当前限制

本轮开发期间已完成的验证：

- 13 项服务集成测试通过，覆盖成员数据隔离、报告文件、MCP、模型选择、自定义配置及密钥处理等流程。
- 9 项指标汇总测试通过，覆盖单位与样本分组、定性与缺失值、日期范围、参考范围变化和原始测量保留。
- 浏览器验证通过：成员切换、报告到指标跳转、模型解析与问答流程、设置分类与搜索、草稿保留，以及桌面、平板和手机布局。保存与多模态流程使用过临时档案、模拟模型；Magpie 文字及图片转发另使用无健康信息的测试内容实测。

当前限制与待处理项：

- 多成员是同一平台内的家庭档案管理，尚无独立账号登录和成员访问权限控制。
- AI 每次问题独立处理，检索上下文有限；图片问答当前不直接读取 PDF 或 DICOM 像素。
- 仅保存报告原件或文字不会自动生成趋势数据，需先核对并录入结构化结果。
- 问答历史目前随数据库磁盘备份保存，不包含在 JSON 记录导出中；原有每日滚动数据库备份仍只覆盖默认数据库。
- 原有解析器回归检查仍有 5 项失败；文档链接检查已回到 0 处断链（检查脚本不再把代码片段里被引用的路径当成真实链接）。
