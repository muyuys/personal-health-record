# 001 数据一致性：健康问题总表 / 总览从 DB 派生

- 优先级：P0（最危险）
- 问题：`data/health.db` 已有 45 条化验（含 eGFR 77.7 等异常），但 `健康问题总表.md` 与 `assets/data.js`（2026-10-27）仍写“肝肾功能暂无化验结果、不能判断正常异常”，用户看到的是错误结论。
- 目标：问题总表 / 总览的检验结论由 DB 自动生成，禁止手写“暂无结果”这类必然过期的判断。
- 范围：健康问题总表、首页/总览、data.js 生成逻辑。
- 验收：新增化验后总表自动出现对应结论与异常标记；全档不存在“暂无结果”静态文案。
- 关联：`docs/产品缺口分析.md`、`server/health_server.py`、`assets/data.js`
