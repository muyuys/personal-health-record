使用指南

个人健康档案是一份存在本机的档案：页面由这台电脑上的一个本地服务提供，数据存在 data/health.db，不上传任何服务器。这份指南按「第一次打开 → 日常怎么用 → 出问题怎么办」的顺序写。

只想了解档案里有什么内容，看 README.md；只想看数据存在哪、怎么备份，直接跳到本文的第 8 节。

1. 打开

双击根目录的 启动健康档案.bat。

  • 会弹出一个黑窗口（这是本机服务，别关），几秒后浏览器自动打开 http://127.0.0.1:8765/。
  • 数据存在 data/health.db（SQLite 数据库），报告照片存在 data/报告原件/files/。不联网，也不上传到任何服务器。
  • 用完了关掉黑窗口即可，浏览器标签页可以留着。
  • 直接把 index.html 拖进浏览器也能打开，但那是「应急模式」：连不上服务，数据退回到浏览器存储，侧栏会显示「浏览器存储模式」。日常请用 bat 启动。
  • 手机上看：把整个文件夹拷到手机、装 Python 跑服务太重。日常建议在电脑上录入，手机通过同一台电脑的局域网地址查看（需要改监听设置，默认只监听本机）。

第一次打开会看到空白的检验页和体重页——这是正常的。 档案里的文字内容（健康问题、检查时间线、用药记录）来自 Markdown 文件整理，已经在页面里；检验结果、体重这类需要你自己填的数据，初始是空的。空不等于正常，也不等于没有。

2. 界面结构

左侧是七个视图，右侧是当前页内容；页头右侧是搜索和该页的主要按钮。

视图 用来做什么 能否在页面里改
总览 一屏看体重/BMI、减重进度、需要处理的事、最近记录、各主题状态 只读（点卡片跳转）
健康问题 每个问题的证据分级、仍需补充什么、关联资料 只读
检验指标 趋势图、最近录入、指标清单、报告原件 可增删改
检查时间线 按日期查检查与就诊 只读
用药记录 历史用药与最近自述用药分开 只读
复诊待办 预约与待补充项，可勾选完成 可勾选
减重记录 体重曲线、7 天晨重基线、胸腰臀围度 可增删改

为什么有的页面不能改：健康问题、时间线、用药是从 docs/健康档案/*.md 整理来的结论性内容，改它要改原件、留痕，不能顺手一点就变。想改这些，改对应的 Markdown 文件，再让页面数据同步（见 7.4）。

同理，复诊待办页头的「添加待办」只是把未完成项列出来给你看，不新建待办——待办本身属于计划清单，要改还是改档案文件。检验结果、体重、围度、报告原件才是页面里真正的可写数据。

右上角的放大镜是全文搜索，输入项目名或关键词直接跳转。

除了这七个视图，左侧栏底部还有一张「数据仅存本机」卡片，点进去是个人资料页：基础资料、档案完整度、数据存储（条数、报告份数、最后保存时间）、导出备份、浏览器数据合并。手机上从底部「更多」进入。

3. 每天/每周要做的事

体重（建议每天晨起、排尿后、进食前）

减重记录页 → 「记录体重」→ 填日期、体重，条件选「晨重」。填了「同日其他时段」的记录不会算进 7 天晨重基线，避免自己骗自己。

围度（不必天天量，两周一次就够）

减重记录页 → 围度卡片右上「记录围度」，或在同一个弹层里切到「胸腰臀围度」页签。胸、腰、臀三项都可以空着，但至少填一项；同一天再记会更新当天那一组，不会多出一条。体重表单里填的腰围也会自动并进围度记录——腰围只有一份，不会两个地方各存一个数。

量法固定下来才有可比性：腰围按肚脐水平一周、呼气末；臀围取最突出处；胸围取乳头水平。围度没有统一参考区间，页面只做你自己的前后对比，不会给「正常 / 异常」的结论。围度是独立的一组测量，不依附体重——没称体重也能单独记。

待办勾选

复诊待办页每项前面有勾选框，做完就勾。勾上只代表「这件事我处理了」，不代表已经就诊、也不代表结论已确认——真正的结论仍然写回档案文件。

新增一次检验（拿到报告后）

见第 6 节，四条路选一条。

4. 检验指标页怎么读

  • 趋势图：选一个指标看历史曲线。浅色带是参考区间；如果某几次报告没印区间，图例会写「N 次无参考区间」，不会说成「均在参考范围内」。

  • 提示列：单独一列，共四个符号。

    符号 含义
    ↑ 高于参考上限
    ↓ 低于参考下限
    · 在参考区间内
    — 报告没印参考区间，无法判断

    深色的箭头表示报告原文就这么标的；半透明的箭头表示报告没标、是按你填的区间算出来的。两者不一样，别混。

  • 报告列：点报告名可以打开那张报告的原件照片。

  • 时间范围：图表右上角可切「全部 / 近 1 年」。没数据时会出现「预览示例」，示例只用于看样式，不写入任何存储；点「退出示例」回到空态。

5. 改已录入的数据

「最近录入」只是预览，固定只放最近 8 条，更早的记录不在那里。但每条记录都有编辑入口：

数据 入口 能做什么
检验结果 检验页页头「全部记录」，或「最近录入」右上角「全部 N 条 →」 全部结果按日期分组列出；按项目 / 备注 / 医院搜索，按类别和来源报告筛选；每行「编辑 / 删除」
报告原件 检验页下方「报告原件」 每份「查看 / 编辑 / 删除」；可改日期、名称、组套、样本类型、医院、备注，也能换图或移除原件
体重 减重记录页「记录明细」表 每行「编辑 / 删除」
围度 减重记录页「围度明细」表 每行「编辑 / 删除」；同一天只有一条，改日期会跟着搬
待办 复诊待办页 点勾选框切换，勾错再点一次

几点说明：

  • 从「全部记录」里编辑，保存后留在原列表，不会被弹回趋势图，方便一次核对一批
  • 改的是本机库里的记录，不会动医院给的原件；原件照片仍在「报告原件」里
  • 删除不可撤销。批量核对前先导一份备份
  • 检验记录按「日期 + 类别 + 项目 + 单位」判重；把日期或单位改掉之后再导入同一份报告，会被当成新记录

6. 把报告变成数据（四条路）

入口都在检验页页头：「导入报告」（批量/图片）和 「录入结果」（一条一条填）。所有解析都在本机完成，不联网。

6.1 粘贴文字（最常用）

  1. 在手机医院 App 或体检报告 PDF 里选中文字，复制
  2. 页面 → 导入报告 → 粘贴文本 → 粘贴 → 「解析预览」
  3. 在预览表里逐行核对：日期、项目名、结果、单位、参考范围、类别
  4. 选「归到」哪份报告（见第 7 节），勾选要写入的行 → 「写入 N 条」

会认得的常见形态：行首序号、*「互认」标记、项目名(酶法) ENG 这种带方法学和英文缩写、下限--上限 双横线区间、页脚 YY-MM-DD 两位年份。

正文里带日期时以正文为准，不会记成你今天导入的日期。

预览表里出现琥珀色竖线 + 项目名下方写原因的行，是「没把握」的行：缺单位、缺参考区间、项目名可能粘连。它们默认不勾选，请看过原件再决定。报告没印单位就按 — 记录，不给你编一个。

6.2 图片识别（和数据库是同一个服务）

一次选多张照片，自动认成文字，再走 5.1 的预览核对。

第一次使用前：

  1. 双击 server/安装依赖.bat，等它跑完（只做一次，约 2 分钟）
  2. 双击 启动健康档案.bat，窗口里出现「识别　引擎就绪」
  3. 页面 → 导入报告 → 图片识别，状态条会变成「识别服务已就绪」

服务没起来也能用数据库，只是图片识别不可用（那是唯一需要额外依赖的功能）。它只监听本机 127.0.0.1:8765，照片在内存里过一遍就丢，不落盘、不上传、不写日志。

它会认错字，常见于这几类：方法学括注、带斜杠的单位、希腊字母、英文缩写里的空格、上下箭头。识别结果是可编辑的文字框，改掉再解析。字迹模糊的行会提示行数。

不想装依赖也完全可以：用手机系统取字（iOS 实况文本 / 安卓长按提取文字）复制过来，一样走 5.1。

6.3 CSV

体检中心导出的表格，需含「项目」「结果」两列表头。Excel 要先「另存为 CSV」。

6.4 JSON 备份

整库恢复，按记录 ID 合并。用于换电脑、换浏览器后把数据搬回来（见 7.3）。

7. 报告原件：让每条数据能追回原件

检验页下方有「报告原件」卡片。

  • 新建：日期、名称、项目组套、检验样本、医院、备注，选一张照片或截图。图片会自动压到长边 1500px 再存（原图太大存不进浏览器）。可以只登记信息不传图。
  • 三层名称：报告名称写医院打印的那一行（如「肝肾常规」）；项目组套写大类（如「生化」「血常规」）；检验样本写血清 / 血浆 / 全血 / 尿液。后两项有候选列表，可直接选，也能自己填；报告上没写就留空。
  • 关联：导入时在预览页选「归到」；单条录入/编辑时选「所属报告」。不关联也可以，表格里显示 —。
  • 追溯：最近录入表的「报告」列点一下就打开原件照片。
  • 走图片识别时选「＋ 新建一份报告」，会把刚才那张照片一起存成原件，不用再传一次；报告表头里的「标本类型」「申请项目」也会自动填进表单，记得核对一眼。
  • 删除报告不会删除数据，只解除关联。

图片存成 data/报告原件/files/ 下的真实文件，不占浏览器配额，只占磁盘空间。

8. 数据存在哪、会不会丢

8.1 存在哪

存在这个文件夹里的一个数据库文件：

位置 内容
data/health.db 检验结果、体重记录、身体围度、待办勾选、报告的登记信息（日期/名称/组套/样本/医院/备注）
data/报告原件/files/ 报告照片，一份报告一个文件，文件名是报告的 id

health.db 是 SQLite 数据库，用记事本打不开；想看内容可以用 DB Browser for SQLite 之类的工具打开，但平时不需要碰它。页面是它唯一的正常入口。

以下情况会丢：删掉或覆盖 data/health.db、data/ 目录所在的磁盘损坏。换浏览器、清浏览器缓存、换电脑都不会影响它（数据不在浏览器里）。

8.2 服务没启动会怎样

页面还能打开，但连不上数据库，会退回浏览器存储：

  • 侧栏那张卡片会变成「浏览器存储模式」，红点 + 提示
  • 这时录入的内容只存在浏览器里，和数据库不是同一份
  • 关掉标签页重开、或者换个浏览器，这部分就看不到了

所以看到「浏览器存储模式」就先双击 启动健康档案.bat，回到 http://127.0.0.1:8765/。如果这时浏览器里确实有想保留的记录，去「个人资料 → 数据存储」点合并浏览器数据，它会按「日期｜类别｜项目｜单位」去重后并进库里，点两次也不会翻倍。

8.3 备份与恢复（服务自动备份 + 建议每月手动导出）

「数据仅存本机」卡片 → 导出备份 → 得到一个 健康档案备份-YYYY-MM-DD.json，这是你磁盘上的真实文件，可以拷到网盘或 U 盘。

  • 自动滚动备份（服务自己会做）：每次启动 server/health_server.py，会在 data/backups/ 下生成当天的一份数据库快照 health-YYYY-MM-DD.db（每天最多 1 份，重复启动不会重复生成），并自动清理超过 BACKUP_KEEP_DAYS（默认 30）天的旧备份。用 SQLite 官方 backup API 生成，服务运行中也能拿到一致快照。GET /ping 会返回 backupDir / backups / lastExportAt / exportDue，方便查看。
  • 用自动备份恢复（整库）：先关掉服务窗口 → 建议把当前的 data/health.db 改名留底 → 把要恢复的那份 data/backups/health-YYYY-MM-DD.db 复制成 data/health.db → 重新启动服务。想回到某天的数据状态，挑对应日期的文件即可。
  • 导出提醒：若距上次导出已超过 EXPORT_REMIND_DAYS（默认 7 天）或从未导出过，服务启动时（以及常驻期间每 6 小时）会在控制台打印提醒，提示你另存一份 JSON。
  • 备份含检验、体重、围度、勾选状态、报告原件图片（v2 格式）。服务模式下由 /api/export 生成，会把 files/ 里的图片读回 base64，所以换一台机器也能完整恢复。
  • 恢复：导入数据 → JSON 备份 → 选文件。先按记录 ID 合并，再按「日期｜类别｜项目｜单位」去重，同一项以文件里的为准，重复导入不会翻倍。也可以只导入别人整理好的部分数据，不必整库覆盖。
  • 更省事的整库备份：关掉服务窗口，把整个 data/ 目录复制走（含数据库和照片）。
  • 原始病历、检查报告 PDF、影像仍要自己另外备份，JSON 里只有整理后的数据。

页面上没有「清空数据库」按钮——这是故意的。真要清空，关掉服务后删除 data/health.db，删之前先导出备份。

8.4 页面上的文字内容从哪来、怎么更新

健康问题、检查时间线、用药记录、待办清单这些只读内容不在数据库里，它们在 assets/data.js 里，是 docs/健康档案/*.md 等原始资料的结构化摘要。

所以要改这类内容，顺序是：

  1. 改对应的 Markdown 原件（例如 docs/健康档案/健康问题总表.md）
  2. 同步到 assets/data.js（这一步不懂代码就让助手做，说明改哪一条即可）
  3. 刷新页面

Tools/生成HTML档案.cjs 只把 README 生成成 README.html，不负责同步 data.js，也不会覆盖 index.html——这点别搞混。

数据库里的记录与 Markdown 是两套东西：删数据库不影响 Markdown，改 Markdown 也不影响已录入的记录。

9. 手机上

宽度小于 860px 自动切换：左侧目录收起，底部变成 4 个 tab + 「更多」。表格会隐藏单位、参考范围列，单位跟在内联显示；提示列始终保留。

文字框在窄屏改成换行显示——列会对不齐，但比右半边看不见强。

10. 出问题怎么办

打开后数据是空的 先确认地址栏是 http://127.0.0.1:8765/，并且侧栏写着「数据已入本机库」。如果显示「浏览器存储模式」，说明服务没起来，先双击 启动健康档案.bat。

改了页面没变化 浏览器缓存了旧文件。Ctrl + F5 强制刷新。

图片识别提示「连不上本机识别服务」

  1. 黑窗口是不是关了？重新双击 启动健康档案.bat
  2. 窗口里有没有报错
  3. 点「重新检测」
  4. 如果提示端口被占用，说明已经有一个在跑，直接用就行

报告图片存不进去 / 提示存储空间不足 这是浏览器存储模式才会遇到的限制（约 5 MB）。双击 启动健康档案.bat 改用数据库就没有这个上限了。

把整个文件夹拷到另一台电脑后，图片识别打不开 server/.venv 是这台机器上装好的 Python 环境（约 300 MB），拷过去通常不能用。在新电脑上重新双击一次 server/安装依赖.bat 即可。这个目录不参与任何备份，删了不影响数据。

导入后日期不对 检查报告正文里有没有印日期。有日期以正文为准；没有才用你在弹层里填的默认日期。

导入的行被跳过了 预览页下方「跳过 N 行，查看原因」会写每个原因。常见是「这一行没有数值」，比如页脚、标题、备注。

11. 边界（重要）

  • 这个页面是整理工具，不是病历。它汇总、导航、画趋势，不替代医院报告原件、不替代医生解读。
  • 参考区间和 ↑/↓ 只说明「相对区间的位置」，不是诊断。不同医院区间不同，跨院数据直接比可能失真。
  • 空白代表没记录，不等于正常、不等于没有症状、不等于数值为 0。
  • 历史用药不等于当前用药。文件夹名、未验证的推测不等于确诊。
  • 证据一律分级：医院报告 / 本人描述 / 辅助分析 / 建议计划。看结论时先看它属于哪一类。
